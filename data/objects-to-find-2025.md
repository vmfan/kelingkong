# Objects to Find (2025)

A scavenger list separate from the landmarks, carried over from the *Rules & Point
System* tab (W36:AD36). The *Landmarks* tab lists only the first five; the seven-item
version below is authoritative — see `../docs/2025/data-audit.md` item 5.

1. Cha Chaan Teng
2. Dim Sum
3. Bolo Bun
4. Egg Waffle
5. Mango Mochi
6. Dai Pai Dong
7. Milk Tea

## Use in 2026

These are not tied to any district, so they don't interact with set bonuses. The intended
2026 use is as **Chance-style bonus cards**: a small flat currency reward for
photographing one, claimable once per team per object.

Because they can be found almost anywhere, they give a team something to do while walking
between landmarks or waiting for a game post heat — filling exactly the gaps that would
otherwise be dead time.

Reward sizing is deliberately small (see `../docs/2026/economy.md`); these should never
compete with buying a landmark.
